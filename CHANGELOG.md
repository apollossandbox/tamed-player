- Cleaner project page: cover, title, one info line and one row of actions.
- Folder projects for loose songs and collaborators.
- Released or target release date.
- Drag projects in the sidebar into any order; type shown under the name.
- Export Disc: artwork, 3D CD, tracks and tracklist in one zip.

- CD viewer opens still and facing front. Arial throughout.
